# no style

無意識の動きからあなたのスタイルを診断するインタラクティブ体験。

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開く。

## ビルド

```bash
npm run build
npm run preview
```

## 診断スタイル

| スタイル | 特徴 |
|---|---|
| DEEP OBSIDIAN | 静寂・重力・内省 |
| HARMONIC FLOW | 秩序・優雅・一貫性 |
| COSMIC KINETIC | 躍動・混沌・情熱 |
| REACTIVE ECHO | 好奇心・反応・共鳴 |

## 体験の流れ

1. マウスを動かすと診断開始
2. 粒子が逃げたり近づいたりし始める
3. 左上の「← back」ボタンを追いかけてみて（逃げます）
4. 10,000px 移動すると結果が出る
