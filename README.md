# 行動診断アプリ（Behavior Analysis App）

Reactで作成した、ユーザーの行動ログから性格傾向を可視化するWebアプリです。

---

## 🔍 概要
このアプリは、ユーザーの行動データをもとに傾向を分析し、  
「DeepObsidian」などのタイプに分類して可視化します。

---

## ✨ 主な機能
- 行動ログの記録・解析
- リアルタイムでのスコア計算
- タイプ分類（例：DeepObsidian / HarmonicFlow）
- インタラクティブなUI表現

---

## 🛠 使用技術
- React
- JavaScript
- Vite
- Canvas / DOM操作

---

## 🎯 工夫した点
- 状態管理をシンプルに設計
- 視覚的に理解できるUI設計
- 行動データをリアルタイムに反映
